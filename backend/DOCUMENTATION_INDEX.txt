  1. Edit: backend/app/services/evaluation.py
  2. Update WEIGHTS dictionary
  3. Note: Must sum to 1.0

================================================================================
                    TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'app'"
  Fix: cd backend (must run from backend directory)

Problem: MongoDB connection error
  Fix: Normal! App works offline. MongoDB not required for development.

Problem: .env file not loading
  Fix: File must be at backend/.env (not backend/app/.env)

Problem: Port 8000 already in use
  Fix: uvicorn app.main:app --reload --port 8001

Problem: Import errors
  Fix: Check all __init__.py files exist in every package directory

See SETUP_COMPLETE.txt for detailed debugging guide
