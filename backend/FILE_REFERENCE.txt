CRITICAL IMPORTS TO VERIFY
===========================

If you see import errors, check these first:

1. Pydantic v2 Compatibility
   - Use: from pydantic import BaseModel, Field, field_validator
   - NOT: from pydantic import validator
   - ClassVar must be imported for class-level constants

2. Absolute imports (no relative imports)
   - USE: from app.config import settings
   - NOT: from .config import settings
   - This allows running from any directory within backend/

3. Optional types
   - USE: from typing import Optional
   - Then: Optional[str] instead of str | None

4. All imports must exist:
   - pydantic ✓
   - pydantic-settings ✓
   - pymongo ✓
   - fastapi ✓
   - python-dotenv ✓ (for .env loading)

RUNNING THE BACKEND
===================

Command (from backend directory):
  python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Alternative:
  cd backend
  uvicorn app.main:app --reload

API endpoints will be available at:
  - http://localhost:8000/docs (Swagger UI)
  - http://localhost:8000/redoc (ReDoc)
  - http://localhost:8000/health (Health check)
  - POST http://localhost:8000/api/trips/validate (Trip validation)

COMMON FILE EDITS
=================

To add a new field to TripRequest:
  1. Edit: backend/app/models/trip.py
  2. Add field with type hint and Field()
  3. Add validator if needed

To add a new endpoint:
  1. Edit: backend/app/main.py
  2. Add @app.get() or @app.post() decorated function
  3. Import any needed models/services

To adjust costs:
  1. Edit: backend/app/services/budget_engine.py
  2. Change constants like DEFAULT_MEAL_COST_PER_DAY
  3. Update docstring with new values

To change scoring weights:
  1. Edit: backend/app/services/evaluation.py
  2. Update WEIGHTS dictionary in EvaluationScore
  3. Note: Must sum to 1.0
  4. Update evaluation methods to use new weights

To add new API key:
  1. Edit: backend/app/config.py
  2. Add new field: your_new_key: Optional[str] = None
  3. It will auto-load from .env

To add new collection:
  1. Edit: backend/app/database.py
  2. Add property: @property def your_collection(self): return self._db["your_collection"]
  3. Use in main.py as needed

ERROR REFERENCE QUICK LOOKUP
=============================

Error: ModuleNotFoundError: No module named 'app'
  Fix: cd backend (run from backend directory)

Error: MongoDB connection refused
  Fix: MongoDB not running (OK, app works offline)

Error: .env file not found
  Fix: Create backend/.env file (copy from .env.example)

Error: Pydantic validation errors
  Fix: Check field types in TripRequest model

Error: Port 8000 already in use
  Fix: Use different port with --port 8001

Error: Import from pydantic._internal
  Fix: Make sure pydantic==2.5.0 is installed

Error: ClassVar not found
  Fix: Update evaluation.py import to include ClassVar from typing
