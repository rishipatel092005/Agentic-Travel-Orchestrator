================================================================================
COST CALCULATION BREAKDOWN (FOR 5 DAYS, 2 TRAVELERS)
================================================================================

Formula:
──────

1. Meal Cost = $60/day/person × 5 days × 2 travelers = $600
2. Accommodation = $100/night/person × 4 nights × 2 travelers = $800
   (nights = days - 1, so 5 days = 4 nights of accommodation)
3. Transportation = $20/day/person × 5 days × 2 travelers = $200
4. Activity Cost = $0 (no activities in basic request)
5. Subtotal = $600 + $800 + $200 + $0 = $1,600
6. Contingency = $1,600 × 10% = $160
7. Total = $1,600 + $160 = $1,760

Budget Alignment:
─────────────────
- User Budget: $3,000
- Estimated Cost: $1,760
- Difference: +$1,240 (under budget)
- Percentage Used: 58.67% (good!)


================================================================================
SCORING SYSTEM EXPLANATION
================================================================================

Budget Score (0-100):
──────────────────────
- 100: Cost ≤ 80% of budget (great buffer)
- 85:  Cost 80-90% of budget
- 70:  Cost 90-100% of budget
- 50:  Cost 100-110% of budget (slightly over)
- 0:   Cost > 110% of budget (significantly over)

For our example: $1,760 / $3,000 = 58.67% → Score: 100 ✓


Preference Score (0-100):
──────────────────────────
- Based on activity categories matching user interests
- Example interests: ["culture", "food", "history"]
- Current: 0 activities → Score: 50 (neutral, no data)
- Future: When activities are added, score will increase if they match interests

Example scoring:
- 80%+ match → 100
- 60-80% match → 80
- 40-60% match → 60
- 20-40% match → 40
- 0-20% match → 20


Activity Diversity Score (0-100):
──────────────────────────────────
- Based on number of unique activity categories and density
- Current: 0 activities → Score: 0
- Example:
  - 1 activity per day with 5 unique categories → 75+
  - 3 activities per day with 3 unique categories → 60+
  - 1 activity per day with 1 category → 20

Target: 3-5 activities per day, 4-6 unique categories


Overall Score (Weighted Average):
──────────────────────────────────
(100 × 0.30) + (50 × 0.25) + (0 × 0.10) + 
(50 × 0.20) + (50 × 0.15) = 30 + 12.5 + 0 + 10 + 7.5 = 60.0

Weights:
- Budget: 30% (most important)
- Preferences: 25%
- Activity Diversity: 10%
- Weather Suitability: 20% (placeholder)
- Travel Efficiency: 15% (placeholder)


Replanning Decision Logic:
──────────────────────────
Replanning recommended if:
- Overall score < 50 OR
- Budget score < 30 (significantly over budget) OR
- Preference score < 40 (poor interest match)

Example: If budget_score = 100, but preference_score = 20, overall = 60
→ Recommendation: "Add more activities matching your stated interests"


================================================================================
LIKELY ERRORS & DEBUGGING GUIDE
================================================================================

ERROR 1: ModuleNotFoundError: No module named 'app'
──────────────────────────────────────────────────

Cause: Not running from the correct directory

Fix:
  cd backend  # Must be in backend directory
  uvicorn app.main:app --reload

Error message indicates you're running from:
  AI_Trip_Planner-main$ uvicorn app.main:app  # WRONG

Should be:
  AI_Trip_Planner-main/backend$ uvicorn app.main:app  # CORRECT


ERROR 2: MongoDB connection refused
─────────────────────────────────────

Cause: MongoDB server not running locally

Fix Options:
  1. Install MongoDB locally: https://docs.mongodb.com/manual/installation/
  2. Start MongoDB: mongod (Windows) or brew services start mongodb-community (Mac)
  3. Or use MongoDB Atlas (cloud): Update MONGODB_URI in backend/.env

App behavior:
  - LOGS: "MongoDB connection failed... Running in offline mode"
  - RESULT: /health endpoint shows "database": "disconnected" ✓
  - ENDPOINT: /api/trips/validate still works! ✓

This is expected and fine for development.


ERROR 3: .env file not being read
──────────────────────────────────

Cause: .env file in wrong location or format incorrect

Fix:
  1. Ensure backend/.env exists (not backend/app/.env)
  2. Format must be: KEY=value (no quotes)
  3. Example:
     MONGODB_URI=mongodb://localhost:27017
     DEBUG=True
  4. No spaces around = sign

Verify:
  python -c "from app.config import settings; print(settings.database_name)"


ERROR 4: Pydantic validation errors
────────────────────────────────────

Example response:
  {
    "detail": [
      {
        "type": "value_error",
        "loc": ["body", "budget"],
        "msg": "ensure this value is greater than 0",
        "input": -100
      }
    ]
  }

Causes and fixes:
  - days: 0 or negative → Must be > 0 and ≤ 365
  - travelers: 0 or negative → Must be > 0 and ≤ 50
  - budget: 0 or negative → Must be > 0
  - interests: empty list → Must have at least 1 interest
  - destination: empty or whitespace → Must be non-empty string
  - max_daily_travel_minutes: < 30 or > 1440 → Must be 30-1440 minutes

Example valid request:
  {
    "destination": "Paris",
    "days": 5,
    "travelers": 2,
    "budget": 3000.0,
    "interests": ["culture"],
    "max_daily_travel_minutes": 180
  }


ERROR 5: Port already in use (Address already in use)
───────────────────────────────────────────────────────

Cause: Port 8000 already in use by another process

Fix:
  Option 1: Kill the process using port 8000
    Windows: netstat -ano | findstr :8000
    Then: taskkill /PID <PID> /F
  
  Option 2: Use a different port
    uvicorn app.main:app --reload --port 8001

  Option 3: Find what's using port 8000
    Windows: Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess


ERROR 6: ImportError: cannot import name 'X' from 'app.models'
───────────────────────────────────────────────────────────────

Cause: Missing __init__.py files or wrong import

Fix:
  1. Verify __init__.py exists in:
     - backend/app/__init__.py ✓
     - backend/app/models/__init__.py ✓
     - backend/app/services/__init__.py ✓
  
  2. Import from correct path:
     WRONG: from models import TripRequest
     RIGHT: from app.models import TripRequest
  
  3. Run from backend directory:
     cd backend


ERROR 7: AttributeError: 'NoneType' object has no attribute X
──────────────────────────────────────────────────────────────

Cause: Database not initialized or offline

Note: This should NOT happen in current implementation because
we use lazy initialization and graceful fallback.

If you see this:
  1. Check logs for MongoDB errors
  2. Verify database.py's is_connected() check
  3. Ensure __init__.py files are present
